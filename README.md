# Car Sales Performance Dashboard (Power BI)

An interactive Power BI dashboard analysing car sales by brand, region, month and salesperson.

## What the dashboard shows

- **KPIs:** total units sold, total sales value, total cost and profit/loss
- **Monthly sales** trend
- **Product mix** across brands (Jeep, Porsche, Audi, Mercedes, BMW, Mini and others)
- **Sales by region** with a regional breakdown table
- **Salesperson performance:** units, sales value and cost per seller
- **Filters** for year-month, product and region
